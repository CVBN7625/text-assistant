# 文本处理与 AI 辅助阅读工具

> 本项目用于学习交流及本地个人使用。AI / 翻译 / OCR 服务由使用者自行配置密钥；仓库没有预置开发者密钥。密钥保存在当前浏览器或扩展的本地存储中，并从客户端发给用户配置的服务，不提供服务端密钥托管。见 [使用边界](RELEASE_STATUS.md)。

用于整理从网页、PDF 或文献中复制的文本，通过可组合规则减少换行、空格、字符和参考文献格式的手动处理。项目包含共享处理核心、独立网页版和 Chromium 浏览器插件，适合个人工具演示和代码审阅；没有医院上线或患者数据处理验证。

## 已实现

- 文本清理、全半角转换、繁简转换和参考文献格式处理；处理器可以单独开关。
- 自定义替换规则、规则优先级与处理前后执行阶段。
- Web 端文本处理、历史记录、翻译、图片翻译、OCR 和自定义 AI 处理页面。
- Manifest V3 插件的选区/剪贴板处理、右键与快捷操作，以及翻译、OCR、AI 后台服务。
- AI 配置支持 OpenAI-compatible / Anthropic-compatible 协议，输入与输出限制、超时、重试及 JSON 结果校验。
- 插件配置备份默认排除凭据；用户显式选择敏感导出时才会包含凭据。
- 两端各自管理配置与皮肤。Web 和插件只共享 Core，不共享运行时存储。

翻译、OCR、AI 的真实服务调用依赖用户配置、上游权限、网络和可能产生费用的服务，本次没有验证真实集成。已有测试使用模拟响应，不代表上游服务可用或额度一定准确。

## 技术栈与目录

Vue 3、TypeScript、Vite 5、Naive UI、pnpm workspace、Vitest、Chromium Manifest V3；Core 使用 opencc-js 和 pangu。

```text
packages/core/       处理器、配置、历史、规则与测试
packages/web/        网页应用、服务适配与测试
packages/extension/  插件前后台、页面、静态资源与测试
scripts/             字体生成、插件打包检查
docs/                外部 OCR 模型说明
THIRD_PARTY_LICENSES/ 第三方许可原文
```

两个客户端依赖同一个 Core；本仓库与 AI 榜单项目无运行依赖。

## 安装与启动

本次使用 Node.js 24.16.0、pnpm 11.5.2 验证。建议使用 Node.js 24 LTS 和 `package.json` 声明的 pnpm 版本。需要现代 Chromium 浏览器。

在仓库根目录执行：

```bash
corepack pnpm install --frozen-lockfile
corepack pnpm dev --host 127.0.0.1
```

打开 <http://127.0.0.1:3001>。启动脚本会先构建 Core，避免干净克隆时找不到共享模块。

生产构建与本地预览：

```bash
corepack pnpm build
corepack pnpm --filter web preview --host 127.0.0.1
```

插件本地验证：

```bash
corepack pnpm build
corepack pnpm package:extension:check
```

在 Chromium 的扩展管理页启用开发者模式，选择“加载已解压的扩展程序”，指定 `packages/extension/dist`。本次验证了构建、Manifest 和打包检查；**没有完成插件安装后的浏览器运行验收**，也没有发布到应用商店。

## 无凭据示例流程

1. 打开“文本处理器”，勾选“全角转半角”。
2. 输入 `ＡＢＣ１２３`，点击“处理文本”，结果为 `ABC123`。
3. 打开“历史记录”查看输入与处理结果。
4. 在“自定义规则”配置规则，再回到处理页勾选参与本次处理的规则。

前 3 步已在独立无头浏览器上下文验证；自定义规则服务有单元测试，完整规则编辑 UI 流程未在本次逐项验收。

## 配置与安全边界

- 无凭据文本处理不需要 `.env`。`.env.example` 仅说明当前配置边界，不包含可用密钥。
- 不要将开发者或生产 API Key 写入 `VITE_*`：这会把值打包到浏览器。
- 现有外部服务配置来自两端本地设置页面，网页使用 localStorage，插件使用扩展存储。它们不是加密的服务端凭据库。
- 开发模式为百度文本/图片翻译提供同源代理；`vite preview` 与静态托管不包含该生产代理。Web OCR 和自定义 AI 服务还可能受 CORS 限制。
- 插件权限包含访问网页、剪贴板、选区与存储；仅在理解权限后本地试用。
- 不使用真实患者、账号或其他敏感资料作为演示输入。不要提交用户配置导出、历史记录、PEM 或 CRX。
