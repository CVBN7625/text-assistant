# 腾讯云 OCR 模型接入说明

## 已接入模型

| Web 选项 | 腾讯云 Action | 推荐场景 |
| --- | --- | --- |
| 通用印刷体识别（基础版） | `GeneralBasicOCR` | 默认选择；网页截图、书籍、普通中英文图片 |
| 通用印刷体识别（高速版） | `GeneralFastOCR` | 清晰且排版简单、优先追求速度的图片；新账号需确认接口可调用 |
| 通用文字识别（高精度版） | `GeneralAccurateOCR` | 小字、模糊、倾斜、复杂背景 |
| 英文识别 | `EnglishOCR` | 纯英文印刷体图片 |

所有模型通过腾讯云 OCR API 3.0 端点 `https://ocr.tencentcloudapi.com` 调用，API 版本为 `2018-11-19`。

## 未接入资源包

- 通用印刷体识别（精简版）：腾讯云将其列为仅老客户续费相关接口，不适合作为新功能依赖。
- 通用手写体：旧版手写体接口，腾讯云建议使用通用文字识别高精度版。
- 文档抽取基础版、多模态版：面向文档结构化解析，不是普通逐行 OCR，返回结构和成本模型不同。
- 图片文字识别基础版：资源包覆盖的能力与当前普通文字提取目标不同，不直接对应现有统一文本结果。
- 文本图像增强：只处理图片清晰度和版面，不返回识别文字；可作为后续 OCR 前处理能力。

## 选择建议

1. 普通网页截图优先选择基础版。
2. 图片清晰、文字较大且需要更快响应时尝试高速版。
3. 基础版识别效果差时切换高精度版，并设置月调用上限。
4. 图片只包含英文时选择英文识别。

Web 对每个模型分别记录本地用量。基础版、高速版和英文识别按照每月 1000 次资源包在 95% 时停止调用；高精度版使用用户配置的月调用上限。

当前 Web 从浏览器直接请求腾讯云 OCR API，目标部署环境必须允许该跨域请求，否则需要提供同源代理。
